# C++ defect report tests

Each `cwgNNN.cpp` / `cwgNxx.cpp` file tests Clang's behavior for C++ Core
Working Group (CWG) issues. A `// cwgNNN: <status>` comment next to a test
records how far Clang implements issue NNN, for example:

```
namespace cwg1 { // cwg1: no
namespace cwg2 { // cwg2: 3.5
namespace cwg3 { // cwg3: 21 c++11
namespace cwg4 { // cwg4: sup 5
namespace cwg5 { // cwg5: partial drafting 2024-03
```

Recognized statuses are `yes`, `no`, `partial`, a Clang version (`21`),
`na`, `na lib`, `na abi`, `sup N` / `sup PNNNNRN` and `dup N`, optionally
followed by `c++11`..`c++26` and, for unresolved issues, the CWG status
(`open`, `drafting`, `review`, `tentatively ready`, `ready`) plus the paper
number or `YYYY-MM-DD` date of the implemented proposed resolution. Each issue
may have only one such comment across this directory.

## Regenerating the C++ DR status page

These comments are the source of the published
[C++ DR status page](https://clang.llvm.org/cxx_dr_status.html),
`clang/www/cxx_dr_status.html`, which is generated by
`clang/www/make_cxx_dr_status` and must not be edited by hand.

Whenever you add or change a `// cwgNNN:` comment, regenerate the page and
commit it in the same change:

```
$ clang/www/make_cxx_dr_status            # downloads the current CWG issue list
$ clang/www/make_cxx_dr_status cwg_index.html   # or use a local copy
```

The `Check C++ DR status page` CI job
(`.github/workflows/clang-cxx-dr-status.yml`) runs
`clang/www/make_cxx_dr_status --check` on pull requests that touch this
directory or the generator. It reuses the issue list stored in the committed
page (no network access) and fails if the page does not match the comments
here, or if `latest_release` in the generator looks stale.

After each Clang major release is published, set `latest_release` in
`clang/www/make_cxx_dr_status` to the new version and regenerate the page, so
that DRs implemented in that release are no longer shown as unreleased. This
step is part of the release checklist in `llvm/docs/HowToReleaseLLVM.rst`.
